# College team context candidates

Twenty fixed arithmetic statistics were built for 731 of 790 historical college-lineage prospects. The 59 unmatched or invalid records remain entirely missing. This is a source-defined college subset, not the complete historical prospect population; later integration must left-join it onto the full fixed population.

The features describe team and opponent points and field-goal attempts per game, effective shooting, free-throw and three-point attempt rates, offensive and defensive rebounding shares, turnovers, assists, steals and blocks. Exact formulas and units are in `feature_dictionary.json`. They use historical game counts and basic box-score totals. Per-game values include overtime. No inferred player totals, possession estimates, opponent-strength adjustments, learned coefficients, NBA outcomes or actual draft positions are used.

Sources cover the 2008–2018 college seasons. Each prospect joins the existing verified focal team and season exactly, with a maximum one-season gap before the draft. All retained games end by May31 of the source season. An entire cached team-season is rejected if any cached game failed the source checks, if valid and raw game counts disagree, or if fewer than20 games remain. This rule cannot establish that the upstream schedule contains every game.

The parent collection checked 62,480 of 63,038 games; 558 were quarantined. It and these features remain candidates: original publication snapshots and complete historical schedules are not certified. `model_eligible` is false, no model was run, and no prior frozen input was changed.

Two independent official university box scores corroborate all60 basic count fields and both reported200-minute totals across the source's39/40-column layouts: [North Carolina versus Michigan State, April6,2009](https://goheels.com/sports/2009/4/6/Stats_13350) and [Villanova versus Michigan, April2,2018](https://villanova.com/sports/mens-basketball/stats/2017-18/michigan-ncaa-championship-/boxscore/2696). These are schema spot checks, not universal validation. The web tool retrieved the official tables; direct HTTP requests returned403. `official_boxscore_projection.json` records transcribed numeric facts with source URLs and explicitly has no raw HTML hash. No article text is published.

Validation includes six tests: calendar/cohort boundaries, rejection of partial cached seasons, future-year exclusion, arithmetic and zero-denominator behavior, full row/order/missingness preservation with invariance after removing post2014 source seasons, and rejection of a changed source hash. An independent reviewer found no remaining arithmetic, date or exact-team join blocker. The candidate table preserves731 fully observed rows,59 wholly missing rows and zero partially populated rows.

Reproduce locally with `python3 work/team_context_v1/build.py`, `python3 work/team_context_v1/test_build.py`, and `python3 work/team_context_v1/verify_schema.py`. The builder requires the separately pinned college source package and existing focal lineage; the schema verification requires private raw source snapshots. The public allowlist excludes raw HTML/error bodies and private identity crosswalks.

`validated_team_game_facts.csv.gz` preserves the full numeric projection of the124,960 validated team-game rows (62,480 games), with hashed team/game keys and exact source-row/side pointers. No raw page text or player identity is included. Re-summing every exported numeric field exactly reproduces all5,741 parent team-season totals.
