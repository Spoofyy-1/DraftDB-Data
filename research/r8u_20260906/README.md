# R8u: individual dated biography fields

This follow-up registers all ten biography fields after the combined family hurt development performance. It fixes the R8t canonical 41-column source-college plus four real consensus-column background. Each field is tested as real and three within-cohort, same-mask shuffled controls, for three model seeds. The baseline has three runs: 123 tasks total, each covering the original 2012–2014 development folds. No combinations, confirmation, held-out files or publication are included.

Every single-field/control arm has the identical 45-column background plus exactly one common added column, `slot_041`. The four consensus columns retain their R8t names and order. Training-only coverage keeps all ten candidates; no feature was omitted after scoring. Shuffles preserve each player's missingness and the cohort's observed values; their streams include the feature name, permutation seed, train/validation role, cohort and missingness pattern. Effectiveness and immovable strata are recorded. Real-minus-shuffled paired differences are the primary diagnostic; the narrower baseline cannot isolate added information.

The source data, season cutoffs, original WAR label definition, model configuration, canonical SHA256(pid) ordering and exact-predictor-vector averaging policy remain identical to R8t. Neither identity, actual pick nor any inherited biography predictor reaches TabICL. Raw predictions and canonical tied predictions remain auditable. The constructor fails closed and parameter equality is verified. There is no weight reuse.

The CPU preflight independently loads an unchanged copy of R8t's worker and plan against the same pinned data. Both preparations must match completed R8t `college_consensus_baseline` player, label, component-matrix and ordered-column hashes; their complete 45-column matrices must also match exactly. Query vector hashes are checked against the completed reference. Local and server pandas matrix hashes differ, so this replay is performed in the original server environment; no tolerance or changed input data is used to bypass the reference. GPU execution refuses to start without a successful preflight tied to the frozen worker and plan.

Local checks passed 180 shuffle reorder tests, 123 design checks, exact duplicate/NaN/signed-zero tie tests and eight tamper rejections. The independent code review found no critical blocker. Fixture predictions test aggregation and guards only; they never enter model training or research results. Original source files, R8t files and existing studies are unchanged.

`run_sandbox.sh` disables networking and mounts only this study, its pinned reference/data, the Python environment and cached checkpoint. Four workers run under a two-hour unit limit, 140G host-memory limit and 2200% CPU quota. `prototype_manifest.json` pins code and bundle hashes before the first model; `results/preregistered_plan.json` preserves those hashes during execution. No output is a clean-benchmark certification, significance test or automatic promotion.
