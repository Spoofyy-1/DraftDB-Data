This pilot contains 434 verified pre-draft factual observations for 118 matched prospects across the 2007–2010 classes. Sixty-seven candidate metrics cover Synergy play types, camp invitation status and contemporaneously reported agent representation. These are collected facts, not trained models or measured improvements.

Use `pilot_features_eligible.csv` for the sparse pid/year matrix and `pilot_observations_eligible.csv` for fact-level provenance, publication/update/capture dates, source hashes and exact archived URLs. `metric_dictionary.json` describes units. The `*_quarantined.csv` files are the complete candidate inventory before archival validation; `pilot_observations_pending.csv` contains the 46 unverified 2011 observations. `validation_summary.json` is the final count; `summary.json` is the earlier candidate inventory.

The five source captures all predate the relevant draft. Publication dates alone were not accepted. The validator checks capture dates, exact archive URLs without a fallback redirect, file hashes, unique normalized identities within the same cohort and each fact against its player section. The 2010 articles contain an NBA retrospective about earlier cohorts; that section is excluded. Navigation, profile sidebars and later recommendations are excluded. The 2007 roster was explicitly incomplete, so omitted names are missing rather than zero. Source agent spellings are preserved, and client counts use only that source's contemporary list. Agent names never enter the feature matrix. PPP and PPS remain separate columns. One internally inconsistent finishing value was omitted rather than chosen.

Coverage is 34 players in 2007 (camp), 55 in 2008 (agent listing), 12 in 2009 and 17 in 2010 (situational statistics). Forty-six 2011 observations remain quarantined because the bounded archive query found no pre-draft snapshot. Exact identity matching rejected 174 source-player records, mostly prospects not present in the identity roster; those names were not fuzzy-matched or assigned to another cohort.

The situational family is the best concrete next collection target: finishing, pick-and-roll, isolation, guarded/open catch-and-shoot, pull-up, transition and turnover rates capture play style and shot difficulty that aggregate box scores miss. This is a hypothesis, not evidence that it improves WAR ordering. Expand all positional articles over 2011–2014 first, then preregister one family-level ablation on the existing 2012–2014 development folds with the same incumbent model, seeds and season cutoffs. The current pilot has no coverage in those validation cohorts, so running that comparison now would not test the intended signal. Avoid selecting individual sparse metrics or declaring a winner on this pilot.

`private/` contains downloaded source pages solely for local validation. Do not copy it into the public data repository. Publicly share the numeric tables, metadata, scripts and hashes only. No model/runner files were modified, no target/outcome file was loaded and no test evaluation was run.

To reproduce the bounded collection: run `check_archive.py`, then `fetch_archives.py`, then `validate_pilot.py`. The latter runs `build_pilot.py` and validates the fixed factual inventory against the local captures. These scripts do not read NBA outcomes. Network requests use public Internet Archive CDX/replay endpoints; the captures carry original publisher content and are not sources of model labels.
