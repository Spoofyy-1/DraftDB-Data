# Complete prior selected population, 2007–2011

The new candidate accounts for all **300 selected members, 60 in each cohort**. It retains all 283 previous member IDs and every inherited row field unchanged, adds the 17 previously unrecovered members, and supplies primary-document corroboration for the 43 provisional 2007 records. The original package remains unchanged and is checked against a complete file-hash snapshot.

This completes source membership coverage. It does not certify global identities, training features, labels, calendars, model accuracy, or the entire eligible/undrafted prospect population. No identity key, feature table, player outcome field, or WAR label was read in this pass. The 17 new source members have no identity review yet.

The [Milwaukee Bucks 2007–08 media guide](https://nyc3.digitaloceanspaces.com/sportsarchive-documents/prod/698bdc3c08deb/2008_Media_Guide.pdf) supplies the complete 2007 result table on PDF/printed page 257. Its cover credits the Milwaukee Bucks Public Relations Department. PDF creation and modification metadata both report October 3, 2007. The conservative qualified source-availability date is October 31, 2007. This is an official contemporary document retrieved from a third-party archive mirror; its authorship and vintage are supported by the document itself, not an independent archive timestamp or a first-party checksum.

[ESPN’s original 2007 draft page](https://www.espn.com/nba/draft2007/index) supplies a separate complete first-round result table. Only that table is parsed. The adjacent prospect-stock table contains a literal test row and is excluded. This current rendering corroborates historical membership; it does not establish an independently verified original publication timestamp. The contemporaneous guide provides the qualified date for the 2007 registry.

A [June 24, 2011 ESPN Los Angeles report](https://www.espn.com/los-angeles/nba/news/story?id=6699401), by Dave McMenamin, supplies the missing Lakers selection. Its HTML records publication and modification on that date. Only the membership fact is extracted. The original AP source still supports the other 59 members.

Some published spellings disagree or contain apparent typos. The private variant and discrepancy tables preserve the actual strings and source references. Existing IDs and canonical strings are deliberately unchanged; new source strings are not corrected from memory. These differences require later identity review before any feature or label join. Matching the same historical source selection across reports establishes a membership correspondence, not an NBA-ID or broad-key identity bridge.

The private v2 registry preserves old fields, including their old completeness flags, for auditability. Its added `v2_*` fields describe the completed source coverage and qualified dates. The public `data/membership_facts_v2.csv` is the clean v2 projection: nonordinal hashed IDs, cohort, membership basis, qualified source, availability, completeness, and unresolved global identity status. It contains no actual positions, source line numbers, names, or research crosswalks. IDs and file order never encode actual positions.

The review index requires earlier cohorts and a source available by the independent information cutoff. It rejects partial or unsupported cohorts and emits only IDs/year. Membership does not depend on NBA appearance, outcome availability, or feature coverage. No missing outcome is turned into zero. The package remains `model_ready=false` until identity and dated data joins are independently reviewed.

`private/` stores the roster, source variants, newly recovered members, source bodies, and the original package hash snapshot. `protected/` stores actual positions and their verification provenance. Both use owner-only permissions. Only the seven files in `PUBLIC_ALLOWLIST.txt` are publication candidates; code/tests are excluded because their assertions contain protected selection facts.

Reproduction is offline: run `python3 work/prior_membership_2007_2011_completion/build.py`, followed by `python3 work/prior_membership_2007_2011_completion/test_build.py`. The source pass used the full cap of 12 initiated requests: seven search queries and five HTTP requests. Two tracker URLs returned redirects, which were recorded but not followed. No retries, model runs, or production changes were made.
