# Incumbent data-removal diagnostics

Twelve fixed development-only variants remove input blocks from both model values and coverage calculations. Other variants compare nominal label maturity, a 2010 training window, uniform WAR weighting, and compact skill interactions. The same recorded incumbent weights and three development folds are used. No additional confirmation or 2019–2026 test evaluation is authorized by this script.

The purpose is to understand dependence on inherited data and timing assumptions. No result is a certified test accuracy or an automatically promoted champion. A model with fewer uncertain features is preferable only when its full provenance and appropriate validation support it.

Data hashes, sandbox rules, and source model functions are supplied with the experiment.
