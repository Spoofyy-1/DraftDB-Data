R9L compares eight prespecified feature panels on the exact observed-label H s2008_gap1_all_h1 training policy and original query population. Each panel keeps H's original sorted44 columns first, then appends only the selected source family's columns in the frozen order. There is no supervised selector, feature reordering or coverage-based row removal.

The24 outer jobs each fit TabICL32/outlier2 for seeds0/101/202, three deterministic Ridge models (alphas30/300/3000), and CatBoost for those same three seeds:216 fits total. Ridge preserves J's training-only median imputation, missing indicators, scaling and SVD solver. The38 unique recipes cover quarter-weight simplex blends plus equal-thirds for each Ridge alpha, deduplicating repeated recipes with zero Ridge weight. All weights are fixed. Every raw/canonical member and recipe prediction is retained for each seed. The separate fixed-three-seed mode matches J: rank-average each stochastic family across all three seeds, rerank each family average, then blend. Already tied recipe scores are validated directly and never re-averaged. Standalone endpoints must be reported separately from actual ensembles.

The model worker sees only a single outer job's training.npz, inference.npz and manifest.json. It never sees query outcome labels, observed-query masks or scoring code. Exact44 raw/canonical TabICL and Ridge/J50-50 reference checks belong to the separate root scorer and must pass before interpretation. Full-query development scores remain primary; the frozen complete-target mask is secondary. Pre2019 development reuse, retrospective source vintages, incomplete original population and feature-width effects remain explicit limitations. This study does not measure or promote a2019+ benchmark model.
