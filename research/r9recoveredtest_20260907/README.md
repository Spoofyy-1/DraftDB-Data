The recovered archived gen11 blend is fixed by its saved identity before this 2019–2025 benchmark. Its rich-input weights are 25% TabICL and 75% Ridge; thinner inputs use the TabICL plus quantile-residual XGBoost hybrid. The primary prediction averages ranks within each model family over three fixed seeds before applying those weights. Other outputs are registered diagnostics and cannot select a new model using these test answers.

Seven test-year jobs require 182 fits, scheduled with four immediately refilled workers. Model processes see only their own input bundle, read-only code/runtime/checkpoint and writable output folder, with no network or benchmark answers. All seven output files are verified and frozen before the host scorer opens any answers. The scorer appends one hash-chained ledger entry and preserves the immutable result.

For test year Y, training includes only earlier draft cohorts from 2007 onward and finite observed WAR seasons actually ending by Y−1. Each target uses up to five contiguous observed seasons, discounted by 0.85, clipped to ±40 and Gaussian-ranked within cohort. Missing training WAR is never zero-filled. Inner-fold feature selection and target normalization use only inner training rows. Query actual draft order and outcomes are never predictors.

This is a mechanism adaptation, not an exact reproduction of the historical 50.6% model: it uses 127 reviewed numerical inputs instead of the original 257, explicit calendar limits and deterministic inner folds, with no unverified legacy features or original shrinkage. Training-label coverage ends in 2022, leaving allowed 2023–2024 seasons unavailable in the later tests. Original feature publication vintage and complete historical population coverage are not certified.

The primary metric is unweighted mean full-available-drafted-pool Spearman ×100 across 2019–2025. The 2020–2025 mean is also reported to match the years of the historical 50.6% result. Inherited benchmark scoring assigns zero to missing outcome components; the fully observed target subset is a separate secondary measurement. This historically reused benchmark is diagnostic, not an untouched holdout, and percentages are order correlations rather than exact-position accuracy.

Only explicit allowlisted code, registration, aggregate proofs, anonymous predictions and scores may be published. Private training arrays, source WAR facts, outcome answer files and label-bearing NPZ files stay on the server.
