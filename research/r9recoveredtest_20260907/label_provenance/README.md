These private CPU exports prepare the archived gen11 target semantics for testing the recovered stack on draft classes2019–2025. Settings are fixed by the parent task: training starts with2007, includes all available earlier prospects with a finite observed contiguous WAR prefix, and uses up to five verified seasons. The target is sum(.85^(ordinal−1) × WAR), clipped to[−40,40], then Gaussian-ranked within each admitted training cohort. Missing training outcomes are never filled with zero.

For each query yearY, every training player belongs to a prior class and every accepted fact has an actual NBA season ending byY−1. The exporter binds the reviewed R9stacktest h1 provenance chain back to its original five-ordinal calendar-broker bundles, verifies their hashes, and rechecks every accepted fact against the pinned actual-season source. For2019 it also recreates the original broker facts from the eligible cells of the pre2019 training snapshot, then requires all six derived arrays to match exactly. It opens no vault, scoring file or current-query outcome file and performs no fitting, predictions or scoring. Existing eligible earlier-cohort facts are the only future-class labels reused.

Server-only root: `/home/ubuntu/nba/handoff/r9recoveredtest_labelprep/exports`.

- `training/prefix5/YYYY/training.npz` has exactly `pid,draft_year,label_value,y,prefix_length,season_end_max`.
- Each training directory has a private eligible-facts CSV and manifest. Facts stay at the root data authority and are never mounted into a model worker.
- `queries/YYYY.npz` contains only `pid,draft_year`, retaining the identical full drafted query population and order from R9stacktest. No X or query truth is exported.
- `manifest.json` binds seven training exports, query metadata, all sources, calendar audits and the2019 replay. `verification.json` independently recomputes saved sums, Gaussian ranks, date bounds, query disjointness, hashes and private permissions.

The verified calendar ends in2022. The2024 training export therefore lacks2023 seasons; the2025 export lacks2023–2024 seasons. Those missing outcomes stay absent. Exact source and admitted-label maxima are reported for each year. Feature population completeness and publication vintages remain unproved, and the2019–2025 benchmark has been reused historically. The preparation does not claim clean generalization or an accuracy improvement.

Only code and aggregate/hash proofs return to the Mac. All arrays/facts remain private on the server under0700 directories and0600 files. There is no automatic GitHub publication and no changes to the earlier O exports.
